# SI24R1_init
SI24R1_init
SI24R1 2.4G 无线模块 STM32 驱动，兼容 NRF24L01 寄存器，发射功率更高。基于 SPI 通信，支持 32 字节一包收发，可切换收发模式。
配套 IMU 姿态解算项目，用于无线传输 MPU6050 姿态数据。

特性：

- SPI 底层读写，封装寄存器读写、缓冲区收发
- 支持切换 TX/RX 模式
- 一包最大 32 字节
- 可配合中断引脚检测接收完成

使用：
调用`SI24R1_Init()`初始化；`SI24R1_TxPacket()`发包；`SI24R1_RxPacket()`收包。

注意：
SI24R1 寄存器和 NRF24L01 基本一致，RF 功率寄存器配置不同，通信双方频道、地址、包长必须一致。
